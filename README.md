# Uy mashq — APK

1. GitHub'da yangi repo oching (masalan `uy-mashq`).
2. Shu papkadagi hamma narsani (yashirin `.github` papkasi bilan) repoga yuklang.
3. **Actions** bo'limida «APK yig'ish» o'zi boshlanadi (5–8 daqiqa).
4. Tugagach, ish ichidagi **Artifacts** → `uy-mashq-apk` ni yuklab oling, zipdan `app-debug.apk` ni chiqarib telefonga o'rnating.

Dasturni yangilash: faqat `www/index.html` ni almashtiring — APK qayta yig'iladi.
